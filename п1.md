## Задание 1. WBS

Система управления задачами

1. Проектирование
   1.1 Анализ требований
   1.2 Проектирование базы данных
   1.3 Макет интерфейса
2. Backend
   2.1 Регистрация и авторизация
   2.2 API создания и редактирования задач
   2.3 Назначение исполнителей и изменение статусов
   2.4 Поиск и получение списка задач
3. Frontend
   3.1 Формы регистрации и входа
   3.2 Список задач и поиск
   3.3 Создание и редактирование задачи
   3.4 Назначение исполнителя и смена статуса
4. Тестирование
   4.1 Проверка регистрации и входа
   4.2 Проверка работы с задачами
   4.3 Интеграционное тестирование
   4.4 Исправление ошибок

## Задание 2. Контрольные точки

1. Утверждены требования.
2. Готова база данных и макет интерфейса.
3. Готова основная функциональность (backend и frontend).
4. Завершено тестирование.
5. Продукт передан заказчику.

## Задание 3. Зависимости

Проектирование базы данных и макет интерфейса зависят от анализа требований.
Backend зависит от готовой базы данных.
Frontend зависит от макета интерфейса.
Авторизация должна быть готова раньше, чем работа с задачами, так как задачи привязаны к пользователям.
Назначение исполнителей и смена статусов зависят от готового API создания задач.
Интеграционное тестирование зависит от готовности backend и frontend.
Исправление ошибок зависит от результатов тестирования.

Параллельно можно выполнять проектирование базы данных и макет интерфейса, а затем разработку backend и frontend.
